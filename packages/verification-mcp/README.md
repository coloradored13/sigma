# sigma-public-verify

Offline quotation-presence checks and optional model assessments. External assessment is disabled by default and requires explicit host policy and public evidence. Quotation presence and model agreement do not establish truth.

Version 0.1.0a1 is part of the independent Sigma Public alpha workspace.
Install the compatible four-package wheel set together until publication.
See the workspace README, SECURITY.md, and docs/CONTRACTS.md for the complete
workflow, supported Linux development environment, and privacy boundaries.

No legacy configuration, database, credentials, or Git history is bundled.
The API and runtime schema are provisional; use fresh public-only stores.

Apache-2.0.
